⚡ Cấu Hình Supabase Cloud Database

Chế độ Offline / Sẵn sàng kết nối

Kết nối cơ sở dữ liệu Supabase giúp bạn lưu trữ thực đơn, khách hàng tích điểm, đánh giá, góp ý và vòng quay may mắn vĩnh viễn trên Cloud, đồng bộ Realtime giữa mọi thiết bị.

Lấy tại: Supabase Dashboard → Settings → API → Project URL
Lấy tại: Supabase Dashboard → Settings → API → Project API Keys (anon public)

📋 Hướng dẫn tạo bảng trên Supabase trong 1 phút:

  1. Đăng nhập Supabase.com và mở Project của bạn.
  2. Vào mục SQL Editor trên menu bên trái của Supabase.
  3. Mở file supabase_schema.sql trong thư mục dự án, copy toàn bộ nội dung và dán vào SQL Editor, sau đó nhấn Run.
  4. Vào Settings → API copy Project URL và Anon Key dán vào 2 ô bên trên và bấm Lưu & Kết Nối Cloud.
